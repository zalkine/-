# היער של גוני 🌲

משחק תרגילי חשבון שהמציאה גוני (בת 8).

הדמות הולכת ביער משמאל לימין. כל תרגיל הוא מכשול: שלולית בוץ, שיח פירות יער, בולי עץ, פטרייה ענקית, מלכודת קוצים וארגז.
פותרים את התרגיל, והדמות קופצת מעל המכשול. בטלפון שמוחזק לאורך, המצלמה עוקבת אחרי הדמות מקרוב.
בכל קומה יש 4 תרגילים. בסוף הקומה הדמות מטפסת בסולם שבצד ימין, ומתנדנדת על גפן להתחלה של הקומה שמעל.
יש 3 קומות, ובסוף מחכה האוצר בבית הקטן שבראש העץ.

- **רמות:** קל (עד 20), בינוני (עד 100), כפל, אלוף (הכול ביחד וגם חילוק)
- **כוכב** על כל תרגיל שנפתר בניסיון הראשון
- עובד במחשב (אפשר להקליד מספרים ולהקיש Enter) וגם בטלפון ובטאבלט (מקלדת מספרים על המסך)

## איך משחקים
פותחים את `index.html` בדפדפן (התמונות נמצאות בתיקייה `assets`). זה הכול, אין צורך בהתקנה.
