# היער של גוני 🌲

משחק תרגילי חשבון שהמציאה גוני (בת 8).

הדמות הולכת ביער משמאל לימין. כל תרגיל הוא מכשול: נחל, בול עץ, סלע, שלולית בוץ, שיח קוצים, בור או פטרייה ענקית.
פותרים את התרגיל, והדמות קופצת מעל המכשול.
בכל שורה יש 4 תרגילים. בסוף השורה הדמות מטפסת בסולם ומתנדנדת על גפן להתחלה של השורה שמעל.
יש 3 שורות, ובסוף מחכה תיבת אוצר.

- **רמות:** קל (עד 20), בינוני (עד 100), כפל, אלוף (הכול ביחד וגם חילוק)
- **כוכב** על כל תרגיל שנפתר בניסיון הראשון
- עובד במחשב (אפשר להקליד מספרים ולהקיש Enter) וגם בטלפון ובטאבלט (מקלדת מספרים על המסך)

## איך משחקים
פותחים את `index.html` בדפדפן. זה הכול, אין צורך בהתקנה.
